# PropertyManagementSystem

A property management web application built with **ASP.NET Core MVC**, developed as part of an academic project and later extended with a **RESTful Web API** and a **persistent SQL database**.

## About the Project

The application was originally built as a full CRUD web system for managing a hotel-style business, covering four core entities: Clients, Employees, Rooms, and Reservations. It started with an in-memory data architecture and was progressively extended to include:

- A RESTful Web API layer
- Persistent data storage using a SQL database (migrated from the original in-memory model)

GitHub Copilot was used throughout development, providing hands-on experience with AI-assisted coding workflows across the MVC, API, and database integration stages.

## Technologies Used

- C#
- .NET
- ASP.NET Core MVC
- RESTful Web API
- SQL Database

## Features

- Full CRUD functionality for Clients, Employees, Rooms, and Reservations
- Static repository classes for data access
- Enum-based categories and status handling
- Costa Rica territorial data preloaded for location fields
- Web API endpoints for external data access
- SQL database integration for persistent storage
